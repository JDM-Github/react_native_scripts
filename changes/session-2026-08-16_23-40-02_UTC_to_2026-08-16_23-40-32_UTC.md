## Risks / Follow-ups

- The positional fallback in `parseArguments` accepts a 4th `projectRoot` argument that the old callers never passed; the flag-detection heuristic (`args.some(a => a.startsWith('--'))`) would misroute a positional call whose name or path legitimately begins with `--`.
- The flag parser validates flag names by stepping `index += 2`, which assumes strictly alternating `--flag value` pairs; an odd-length or interleaved argv could pass validation while `flagValue` reads the wrong slot.
