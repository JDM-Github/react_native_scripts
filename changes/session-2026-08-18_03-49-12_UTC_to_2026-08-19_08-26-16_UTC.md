## Key Changes
- **Windows tray build (`--bin`)**: New capability documented in `CLAUDE.md` and implemented across `scripts/build-platform.mjs`, `scripts/electron/main.cjs`, `scripts/electron/package.json`, and `ikaika.script.json`.
  - `--bin` packages the Electron shell as a tray app (closing the window hides it instead of quitting); Windows-only, and gated behind a required, validated `--bin-icon` (must be inside the project, exist, and be `.png/.ico/.jpg/.jpeg`).
  - Tray settings are written per-build to `.build-temp/windows-desktop/desktop.json` (plus icon copy) and copied into the installed app via `extraResources` as `resources/desktop`; `main.cjs` reads it at startup and falls back to plain windowed behavior if missing/unreadable.
  - `.build-temp/windows-desktop` is written for every Windows build (tray or not) since `extraResources` requires the source to exist.
  - `--bin-menu` syntax: `Label:action` items joined by `|`, `-` for separators, `Label:open-url:https://ΓÇª` for links (split-from-left to preserve URL colons); actions validated against a `TRAY_ACTIONS` allowlist kept in sync between build-time and `main.cjs` runtime enforcement (`open-url` is https-only in both).
  - `main.cjs` always appends a Quit item if the configured menu lacks one, and only intercepts `close` when a tray actually exists; tray builds take the single-instance lock by default.
